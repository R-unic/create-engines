## Exceptions

Intended changes that move guarded behaviour or compatibility. Approver: the author's request of 2026-11-18 ("do all of the crossover
work saved for 2.0 that breaks ids and such"), with the throttle body decided as keep. Not yet reviewed line by line.

- **Advancement IDs.** All 110 1.x IDs are gone. 64 rows plus the root are redefined as `<track>/<row>` (`root` for the tab root,
  `chief_engineer` unchanged); 46 hidden rows deleted. `AdvancementTabTest` was rewritten by hand (it pinned 110 files "deleted in
  2.0, not in 1.x"). `driveline/every_gear` is now shown. Progress carries over by `AdvancementMigration` and the
  `PlayerAdvancementsMixin`. Anything referring to an old ID (datapacks, commands, other mods) breaks.
- **Config files and keys.** New files `create_engines-v2-server.toml` and `create_engines-v2-client.toml`; `[engine]` split into
  `[calibration]` and `[limits]`; client `[effects]` split and four keys renamed. A pack's `defaultconfigs/create_engines-server.toml`
  no longer applies. Presets still copy over (`[balance]` and `[features]` unchanged).
- **Create 6.0.10 dropped.** Needs 6.0.11 or newer; the jar metadata range is `[6.0.11,6.1)`.
- **Altitude thinning.** Engines above y 128 make less power by default (`compat.altitudeThinning`). Existing builds at or below y 128
  are unchanged; `compat/behaviour.txt` and `compat/trajectories.txt` did not move. Not guarded by a new baseline entry.
- **Port count curve.** `PortNetwork.flowFactor()` is now `PortFlow.factor`: diminishing returns per opening, crowded openings worth half.
  Every engine with under about two openings per head breathes less (one per head: 90 percent, was 100; one for two heads: 67 percent,
  was 100). `compat/behaviour.txt` and `compat/trajectories.txt` did not move (they set the factor directly). Not guarded by a baseline
  that sees real layouts. The constant 2.3 is a first choice from a six-cylinder sweep.
- **GameTest guard moved by hand.** `aVariableTurbochargerClosesItsVanesOnAThinExhaust`: vanes floor 0.2 to 0.15 (measured 0.177 with the
  one-opening-per-head build, which now breathes at 90 percent). An attempt to keep the old bound by adding extra mouths did not join the
  pipes in the test, so the bound moved instead. Approver: the author's request of 2026-11-18 for the port curve; not reviewed line by line.
- **Test changes.** `ConfigMatrixTest` gained the `altitudeThinning` switch (a new setting, nothing loosened).
- **Not done from the saved-for-2.0 list:** legacy manifold handling (nothing found; `Gears.fromLegacy` kept because 2.0 still opens
  1.0 worlds), the basin fuel recipe review, most of the Aeronautics moving-structure work (only the world-height piece is written, and it has never run: see ROADMAP), the optimization pass.
- **Aeronautics row broken by the Create floor.** Aeronautics 1.2.1's bundled Simulated fails to load on Create 6.0.11 (mixin target `NixieTubeBlock.getPower` missing). `runGameTestServerSable`, `runSmokeAuditAeronautics` and the showcase need a NeoForge 21.1.228+ build and Aeronautics 1.3.2, or the row stays red.
