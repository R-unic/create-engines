## Exceptions

- **2.1, spark fuels need a plug or a pilot shot (existing behaviour):** a plugless engine no longer runs on a spark fuel by compression
  heat from boost (`FuelSpec.needsSpark`, `Combustion.combust`; `PluglessBoostTest`). Moves six lines of `compat/behaviour.txt`, by hand,
  all `run:KEROSENE:{crude,injector,precise}:{1cyl,6cyl}:blower:compression` (plugless blown kerosene); no trajectory, manifest or world
  fixture moves. Approved by: R-unic (2026-11-23, in chat: "yeah add the rule"). Commit: not yet.
- **2.2 (rule 4), new dials and settings:** the alternator's charge rate (a value box, default 100%, nothing existing changes) and three
  server settings for the Dual-Mass Flywheel. Charge rate approved by R-unic (2026-11-23, in chat: "i like the alternator charge rate idea").
  The dual-mass settings are new, so no existing build uses them; the author asked for the flywheel (ROADMAP-3.0, 2.1).
- **2.3, outlines of thirteen existing parts changed:** the selection outline and collision of the alternator, black box, governor, flare
  stack, starter, air intake, exhaust outlet, turbocharger, cam lobe, crank throw, and the bodies of the throttle, MAF sensor and heat
  exchanger, and the flange of a pipe arm, now follow the models (`PartShapes`, `HitboxFitTest`). No saved data, ID or engine number moves.
  Approved by: R-unic (2026-11-23, in chat: "it stands for 2.1").
- **2.8, flywheels buffed (existing behaviour):** the default `flywheelInertia` goes 1.5 to 2.5 and `castFlywheelInertia` 1.0 to 1.6, because
  two Create Flywheels on an inline-4 only took its roughness loss from 11.3% to 5.4% (measured with `RoughnessTest`'s model, crude cylinders,
  rated at 256 RPM; the wheels are inertia 0 / 3.0 / 5.0 / 6.0 and the loss 11.3% / 5.4% / 3.8% / 2.8%). Only the config default moves: a
  world whose config file already holds a value keeps it, and a fresh one spins up more slowly and starter effort is higher. No guard file
  moved: `./gradlew test --offline` ran 1542 tests, all green once `RoughnessTest`'s new test had its bound set to the measured 3.8%
  (the GameTests and the pitest gate were not re-run for this change). New test:
  `RoughnessTest.twoFlywheelsOnAnInlineFourTakeMostOfItsRoughnessLossAway`. Approved by: R-unic (2026-11-23, in chat: "flywheels should be buffed a little").
- **2.9, fuel character: biodiesel, plant oil and spill fire (existing behaviour):** three changes to fuels that existing builds use, each
  named by the author in chat on 2026-11-23 ("Change it now (exception)" for biodiesel and for plant oil, "Spills only, on by default" for
  fire). Approved by: R-unic. Commit: not yet.
  1. **Biodiesel burned as diesel and is now its own fuel** (`FuelSpec.BIODIESEL`, returned by `CEDataMaps.fuelForTags` before diesel, so
     Diesel Generators' biodiesel, which is in `c:diesel` as well, takes it): energy 36 to 33, soot factor 1 to 0.5, sulfur 1 to 0;
     autoignition, air and cold are diesel's. An engine on biodiesel makes less power for the same flow and burns cleaner.
  2. **Plant oil**: `cold_sensitivity` 1.5 to 0.9 (a stone-cold block burns 82% of its heat release before, 89% now), `soot_factor` and so
     sulfur 1 to 1.3. Measured with `Thermal.burnFactor`; with the old 1.5 restored the trajectory test passes, so this one number
     moves all of the trajectory lines below.
  3. **Spills burn by fuel** (`compat.fuelFireByVolatility`, default true): gasoline and methanol 2.0, ethanol 1.5, diesel, biodiesel, kerosene,
     plant oil and used oil 0.5, others 1. A spill lit before burned at three ticks a block for every fuel; now gasoline is two and the
     diesel class six with a 50% chance per try. Only fluid blocks in the world are read; never a tank or a running engine.
  Guards moved by hand: `compat/manifest.txt` fuel.json line (`5c568a10...` to `2d4f347e...`), `compat/trajectories.txt` (the 14 lines of seeds 0, 2, 3,
  7, 8, 9, 16, 19, 20, 27, 31, 34, 35, 39 deleted and re-recorded; `git diff` shows them), `ThermalTest.aColdBlockBurnsFuelWorse...` (plant oil
  now sits between diesel and gasoline), `FuelSpecTest.onlyEthanolCoolsTheChargeAndBurnsCleanOfSoot` (plant oil's soot 1.3),
  `ScriptAndDataSurfaceTest` (nine fuel keys, `data fuel flammability optional 1.0` appended to `compat/script-surface.txt`) and the biodiesel
  assertion in `EngineGameTests`. `compat/behaviour.txt` did not move. **The numbers (0.9, 1.3, 33, 0.5, the flammabilities) are a first
  choice and the author's to tune; no dyno table was made before writing them.**

- **2.6, Create range:** only 6.0.10-281 was tested; the claimed range is `[6.0.10,6.1)`, as in 2.0.2. Needs the author's word that it
