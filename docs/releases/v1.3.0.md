- **Heap: cause found 2026-11-17, accepted by the author ("keep styles, ship +440 MB").** The new `casing_style` property
  (3 values, unreleased until 1.3) on the five pipe blocks (intake manifold, exhaust manifold, heat exchanger, throttle,
  MAF sensor) triples each pipe's block states, and each state carries the 64-way connection multipart; a heap
  histogram showed 7.4 million `KeyValueCondition` lambdas from vanilla's multipart loader. Dropping the property on
  pipes only (private copy, not applied) took the settled heap from 1267 MB to 830 MB (pre-style 752 MB). The author
  chose to keep riveted and louvred cladding on pipes, so the number stays: players pay about 440 MB more RAM at model
  load, and `casing_style` on pipes becomes part of the 1.x promise. Revisit for 1.4 (cheaper pipe models) or 2.0.
