## Changed after the first gate

The author's hands-on pass and signature were on a build from before the later of these changes; which build each box was checked on was not recorded.
The whole machine gate above ran with all of them in.

- Asked for by the author ("20 seconds is way too fast", precision parts should wear slower, janky sounds and timing): a dry piston now takes 120 seconds
  at 128 RPM to seize (was 20 at any speed), longer when slower, 2.5 times as long forged; the banked time survives an engine rebuild; a new
  `seize_warning` sound replaces the one-off play of the `bearing_squeal` loop; `piston_seize1..2` and `gasket_blow1..2` are re-rendered.
- Reported by the author (a rod at 0.99 wear fitted to a stalled engine was thrown with it standing still): no rod, gasket or set of apex seals fails
  while the crank turns slower than 1 RPM.
- Reported by the author (no redstone strength could pick Auto on the Transmission): strengths now map 1 to 13 to that gear, 14 to reverse and 15 to
  Auto. See Exceptions.
- Asked for by the author (battery wear was never seen): with wear on, battery goggles always show it, with a decimal below 10%.
- Asked for by the author (chose "Stall quickly"): each chamber of a failed apex seal set grips the shaft with 40 times a plain cylinder's static
  friction. Wear mode only.
- Switching the wear mode off and on now rebuilds running engines.

## Known issues

Wear mode only, so off by default. All are in the changelog, for 2.3.1. The first three and the last were found by a code audit reading the code; their
fixes were not finished and this gate did not reproduce them.

- A new piston can inherit the old one's dry-running time and seize early.
- A gasket fitted to a head that broke before the mode was switched off can be lost when the mode comes back on.
- For one tick after the mode is switched, an engine can run without its saved failures.
- A worn battery or rotor housing that is broken and placed again comes back as new ([ROADMAP-3.0.md](../ROADMAP-3.0.md)).
- The same audit also listed performance concerns (large battery banks, the Create gear-network walk, the pollution area check), estimated from the code
  and not measured.
